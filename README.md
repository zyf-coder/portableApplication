# 便捷工具

跨端实用工具 Web 应用：**无水印提取** + **证件照制作**。单文件、纯前端、可离线使用。

## 功能

### 无水印提取
- 粘贴抖音 / 快手 / 小红书 / 微博 / B站 等分享链接（支持多行批量）
- 解析结果列表、复制链接、批量下载
- 视频可连带封面保存
- 解析失败时可展开「手动直链下载」

### 证件照制作
- 一寸 25×35mm（295×413px）、二寸 35×49mm（413×579px），300dpi
- 分步向导：选尺寸 → 传照片构图 → 换背景 → 预览导出
- 自动抠图换底（白 / 红 / 蓝 / 青 / 自定义），支持柔和边缘
- 导出 JPG / PNG，**全程本地处理，照片不上传**

## 运行

直接用浏览器打开 `index.html`，或：

```bash
# 本地预览（任选）
python -m http.server 8080
# 或
npx serve .
```

手机访问同一局域网地址即可试用。

## 结构

| 文件 | 说明 |
|------|------|
| `index.html` | 完整应用（HTML + CSS + JS） |

模块划分（逻辑内聚在脚本中，便于拆到 Flutter / FastAPI）：
- `link_parser` — 分享链接识别与解析流程
- `video_downloader` — 直链 / 批量下载、封面
- `id_photo` — 尺寸、构图、导出
- `background_removal` — 四角采样抠图换底

## 接入真实解析后端

当前社交链接为**演示模式**。对接 FastAPI 时，在 `parseOne` 中请求：

```http
POST /parse
{ "url": "https://v.douyin.com/..." }
→ { "media_url": "...", "cover_url": "...", "type": "video"|"image" }
```

直链下载已可用。
